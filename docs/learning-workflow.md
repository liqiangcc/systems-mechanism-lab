# System Mechanism White-box Learning Workflow

## Goal

Build verified system knowledge through source reading, mechanism extraction, experiments, and evidence.

## Workflow

```text
Source Document
    ↓
Directory Index
    ↓
Section Reading
    ↓
Question Extraction
    ↓
Mechanism Model
    ↓
Experiment
    ↓
Observation
    ↓
Conclusion
    ↓
Merge to main
```

## Principles

- Source is separated from derived knowledge.
- Mechanisms must be explainable and verifiable.
- Main branch stores verified understanding, not raw notes.
